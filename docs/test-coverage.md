## Verified exclusions

No separate shipping selector or native dialog was present in the selected shopping workflows. Contact attachment selection is verified separately; the documented server attachment endpoint requires a contact message ID, so message submission and server upload are outside the executed scope. Invoice PDF download is asserted in E2E-01, including file signature and size; see the execution summary for actual generation availability. Guest checkout exists, so authentication is required for account functionality rather than all checkout. No destructive admin operations. User deletion requires admin; unique synthetic accounts remain until demo reset. Mock scenario is separate from backend integration.
