# Reports and retained evidence

The [published Playwright report](https://srenevasanks.github.io/playwright-typescript-automation-framework/playwright/) and [published Allure report](https://srenevasanks.github.io/playwright-typescript-automation-framework/allure/) are the same **17 October 2026 smoke snapshot: 11 passed, zero failed/skipped, Chromium + API, two workers**. They are historical evidence, not the current regression status. The 61-case regression has separate results, including real failures. See [current execution](execution-summary.md).

| Location                                | Purpose                                                            | Git strategy                                    |
| --------------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------- |
| playwright-report*/                     | Native HTML generated by each execution                            | Ignored                                         |
| test-results*/                          | JSON, runtime summaries, screenshots, videos, traces and downloads | Ignored                                         |
| allure-results*/ and allure-report*/    | Raw results and generated Allure HTML                              | Ignored                                         |
| evidence/review-2026-10-18/             | Dated sanitized counts, observations and selected safe screenshots | Explicit curated snapshot                       |
| Existing evidence/*.json                | Historical execution and debugging summaries                       | Preserved                                       |
| reports/playwright/ and reports/allure/ | Frozen sanitized 11-test smoke reports                             | Preserved byte for byte                         |
| gh-pages branch                         | Published copies under /playwright/ and /allure/                   | Existing branch-based Pages publishing retained |

The dated [snapshot manifest](../evidence/review-2026-10-18/published-snapshot-manifest.json) records hashes for the frozen files. Normal test execution never writes to reports/ or curated evidence. The summary helper now defaults to ignored test-results/execution-summary.json rather than a tracked evidence file. Counts come from runner JSON; there are no fixed expected execution totals.

```bash
node scripts/summarize-results.mjs test-results/results.json test-results/execution-summary.json smoke
npm run report
npm run allure:generate
npm run allure:open
```

Allure generation requires Java 17 or later. Give each separate run its own REPORT_DIR, RESULTS_DIR, JSON_REPORT and ALLURE_RESULTS_DIR, then point the Allure CLI at that run's raw directory. Do not merge stale Allure results from different scopes or concurrent runs.

CI uses a fresh checkout, one worker and no retries. It retains failure traces even without a retry, screenshots and videos, and generates/uploads reports after test failures. Artifact names include scope, run ID and attempt. Artifacts expire after seven days; dated sanitized summaries in Git remain available. The raw test reports can contain synthetic credentials, tokens, addresses, and request bodies in traces: they are debugging artifacts, not material to commit or publish without sanitization. Curated JSON includes only counts, titles, versions and selected non-sensitive status evidence. No PDF containing customer details is committed.

There is no portfolio landing page. Existing report URLs stay unchanged. New reports remain tied to the particular run rather than silently replacing published passing evidence.
